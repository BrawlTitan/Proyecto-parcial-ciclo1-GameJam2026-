# Proyecto-parcial-ciclo1-GameJam2026-
Misión Orión: juego de consola en C++ donde pilotas la nave Orion para rescatar personas de la Tierra y llevarlas a la Luna, esquivando lluvia de meteoritos. Hecho en solo 48 horas para la Game Jam 2026 del curso Introducción a los algoritmos UPC. Por @BrawlTitan, @Robben y @usuario3.
